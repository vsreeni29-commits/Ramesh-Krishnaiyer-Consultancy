# Ramesh Krishnaiyer — Tax & Consultancy

A responsive, accessible one-page consultancy website designed for Ramesh Krishnaiyer in Chennai.

## Live website

<https://vsreeni29-commits.github.io/Ramesh-Krishnaiyer-Consultancy/>

## Highlights

- Mobile-first layout with a persistent call action
- Tap-to-call number using `tel:+916383310997`
- Direct email and Chennai map actions
- Interactive service filters for individuals, businesses and organisations
- Service-aware enquiry dialog that prepares a prefilled email
- Scroll reveal, progress indicator and pointer-based hero depth
- Reduced-motion support, keyboard focus states and semantic HTML
- No tracking, backend, framework or runtime dependencies

## Run locally

From this directory:

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173>.

## Validate

```bash
npm test
```

## GitHub Pages deployment

The workflow in `.github/workflows/pages.yml` validates and deploys the site whenever `main` changes.

For the first deployment, open **Settings → Pages** and set **Source** to **GitHub Actions**. Then run the workflow from the **Actions** tab if the initial run happened before Pages was enabled.
